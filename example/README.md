# Mooodier UI Example

This example app demonstrates all the components and features of the Mooodier UI library.

## Features

- **Component Catalog**: Browse all available UI components with interactive examples
- **Theme Settings**: Customize the color scheme by selecting different seed colors
- **Accessibility Settings**: Test accessibility features like large text, high contrast, and reduced animations

## Running the Example

```bash
cd example
flutter pub get
flutter run
```

## Structure

The example app is organized into three main sections:

1. **Component Catalog Page**: Showcases all widgets and components
2. **Theme Settings Page**: Interactive theme customization
3. **Accessibility Settings Page**: Real-time accessibility feature testing

This storybook-style app serves as both documentation and a testing ground for the UI library.
