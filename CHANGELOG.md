# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-02-25

### Added
- Initial release of mooodier UI library
- Design tokens: Spacings, Radii, Durations
- Theme system with Material 3 support
- AccessibilityConfig for large text, touch targets, high contrast, and reduced animations
- Color extensions: `darken()` and `lighten()`
- AnimatedGradientContainer with configurable animation speed (0.1x - 3.0x)
- FrostedGlassContainer for glass morphism effects
- UI components: SurfaceCard, Section, SectionHeader, InfoBanner, ActionButton, CustomListTile
- Text formatting widgets: FormattedText, FormattedTextField with lowercase forcing
- Comprehensive test suite with 213+ tests
- Example app with interactive component catalog
